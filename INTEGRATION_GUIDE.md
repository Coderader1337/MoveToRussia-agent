# Интеграция источников данных для AI-копайлота

## 1️⃣ Яндекс Корпоративная Почта

**Подключение:** IMAP (`imap.yandex.ru:993`) + SMTP (`smtp.yandex.ru:465`)  
**Аутентификация:** Пароль приложения (создается в настройках почты)  
**Как использовать:** IMAP Email trigger в n8n → получаем письма → парсим → отправляем в LLM.  
**Преимущество:** Встроено в n8n, просто настроить

```
GET: Входящие письма, история переписки, вложения, метаданные
```

---

## 2️⃣ Proton Mail

**Подключение:** Proton Mail Bridge (локальный прокси на `localhost:1143`)  
**Статус:** ⚠️ На потом (только ~10% коммуникации, сложнее настраивать)  
**Если нужна:** Установить Bridge, подключить как IMAP

```
GET: Письма из зашифрованных ящиков (если включим позже)
```

---

## 3️⃣ EnvyCRM (API + Webhooks)

**API Key:** Настройки → Интеграции → API → скопировать ключ

**Основные запросы:**

| Что нужно | Endpoint | Метод |
|-----------|----------|-------|
| Данные клиента | `/openapi/v1/client/getContacts/` | POST |
| Поиск сделок | `/crm/api/v1/deal/search/` | POST |
| Поиск лидов | `/crm/api/v1/lead/search/` | POST |

**Пример (cURL):**
```bash
curl -X POST 'https://domain.envycrm.com/crm/api/v1/deal/search/?api_key=KEY' \
  -H 'Content-Type: application/json' \
  -d '{"request": {"filter": {}, "limit": 50}}'
```

**Webhooks (исходящие события):**  
- EnvyCRM → отправляет POST на n8n webhook при создании лида, смене статуса
- Настройка: **Настройки → Интеграция → Webhook** → указать URL n8n

**Получаем:** Статус сделки, ФИО/контакты клиента, ответственный, этап воронки
