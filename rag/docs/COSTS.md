# Оценка стоимости поддержки

Разбивка по статьям расходов. Часть цифр — точные (взяты из кода/реальной
статистики использования), часть — оценочные (тарифы API меняются, точную
сумму по VPS/аккаунтам нужно свежо проверить у провайдеров — см. пометки
"уточнить").

## 1. VPS (сервер)

Бот + self-hosted Qdrant крутятся на одном VPS (`207.244.254.188`,
хостится под root, см. `.cursor/rules/mail-agent.mdc`).

**Стоимость VPS: $8.19/мес.**

Эта сумма является фиксированной базовой стоимостью содержания проекта. В
репозитории также есть чек-лист отдельного VPS для legacy `mail_agent`, но он
к RAG-ассистенту не относится и в расчёт ниже не включается.

## 2. Voyage AI (эмбеддинги)

Модель `voyage-4-large` используется на бесплатном тарифе Voyage AI.

На текущем тарифе предоставляется бесплатный объём токенов. Практическое
ограничение — лимит запросов в минуту (RPM), поэтому длительность индексации
определяется не стоимостью, а RPM и паузами между батчами.

Когда расходуются бесплатные токены:

- **Полная переиндексация** (`--recreate`): весь корпус (~5935 mailbox chunks
  + 290 FAQ) эмбеддится заново. Перед прогоном можно проверить объём:
  `python scripts/index_corpus.py --dry-run` — покажет число токенов и
  справочную оценку по платному тарифу, без вызовов Voyage.
- **Инкрементальная индексация** новых писем — только новые/изменённые chunks
  (тратит бесплатную квоту, обычно небольшая доля от полного корпуса).
- **Каждый вопрос пользователя** — один `embed_query`-вызов на каждый
  извлечённый DeepSeek-ом факт-вопрос (1-8 на сообщение, `voyage_batch_size`
  не влияет на query-запросы, они идут по одному-два). Стоимость query
  эмбеддинга пренебрежимо мала по сравнению с индексацией (несколько строк
  текста против тысяч chunks). На текущем бесплатном тарифе отдельно
  оплачивать эти вызовы не требуется.
- **Ежедневный синк Yandex Disk** (если используется) — эмбеддится только
  diff (added/changed файлы), обычно 0 при отсутствии изменений на Disk.

**Важно:** перед крупной переиндексацией нужно проверить остаток бесплатной
квоты и лимит RPM в личном кабинете Voyage. Если бесплатная квота закончится,
дальнейшая работа может потребовать перехода на платный тариф.

## 3. DeepSeek (LLM)

Для расчёта используем присланный тариф DeepSeek-V4 API, цены указаны за
1 млн токенов:

- `DeepSeek-V4-Flash`, **off-peak**: input cache hit — `$0.007`, input cache
  miss — `$0.22`, output — `$0.66`;
- `DeepSeek-V4-Flash`, **peak**: input cache hit — `$0.014`, input cache miss —
  `$0.44`, output — `$1.32`.

Пиковые часы по UTC: **01:00–04:00 и 06:00–10:00**. В остальное время действует
off-peak-тариф. Цены действуют с 16 августа 2026 года. В коде используется
`deepseek-v4-flash`.

Используется на трёх этапах:

1. **Каждый запрос в боте** — 2 вызова: (а) извлечение фактических вопросов
   (`question_extraction.py`), (б) генерация ответа/письма (`chain.py`).
   Модель `deepseek-v4-flash` (дешёвый flash-тир).
2. **Сборка FAQ-каталога** (`build_faq_llm.py`) — потенциально сотни вызовов
   (extract на каждый двусторонний диалог + merge/semantic-merge батчами) —
   разовая/редкая операция, но может стоить заметно больше, чем повседневная
   работа бота, если пересобирается FAQ с нуля на большом объёме переписки.
3. **Опциональная дистилляция корпуса** (`prepare_rag_corpus.py --distill`) —
   по умолчанию выключена, при включении — один вызов на каждый
   информативный exchange (~тысячи вызовов на весь корпус).

### Как считать стоимость

Формула для одного периода:

`стоимость = input_cache_hit_токены / 1 000 000 × тариф_hit`
`+ input_cache_miss_токены / 1 000 000 × тариф_miss`
`+ output_токены / 1 000 000 × тариф_output`

Точную сумму по текущей статистике посчитать нельзя: `usage_stats.csv` хранит
вопрос, ответ и оценку, но не записывает количество input/output-токенов и
долю cache hit. Поэтому ниже — прозрачная оценка для бюджета, а не
фактический инвойс.

## 4. Реальная интенсивность использования (для оценки бюджета "в стабильном режиме")

Из отчёта `rag/data/usage_report_2026-07-31_2026-08-06.md` (неделя реального
использования, без тестовых запросов разработчика):

- **25 оценённых запросов за 7 дней** (~3-4 в день), 5-6 активных пользователей.
- Каждый запрос = 1 запрос эмбеддинга (Voyage, бесплатный тариф) + 2 вызова
  DeepSeek (extract + generate).

25 запросов за неделю — это примерно **108 запросов в среднем месяце**.
Если для планирования принять на один пользовательский запрос суммарно
20 000 input-токенов и 2 000 output-токенов по двум вызовам DeepSeek, получится:

Тогда содержание проекта при текущей нагрузке составляет ориентировочно:

- **$9.43/мес**: VPS `$8.19` + DeepSeek около `$1.24`.

Это сценарная оценка. Если фактический объём промпта вдвое больше, API-часть
примерно удвоится. Cache hit, наоборот, существенно уменьшит стоимость input.

**Итоговая оценка стабильного месяца без пересборки данных:** примерно
**$8.81–$9.43/мес** при нагрузке и допущениях выше. Voyage остаётся бесплатным
на текущем тарифе, а Qdrant и Telegram не добавляют отдельной платы.

Основной дополнительный расход — разовые операции: пересборка FAQ и
дистилляция корпуса через DeepSeek. Их стоимость зависит от числа токенов и
не входит в месячную оценку выше.

## 5. Что бесплатно (или почти)

- **Qdrant** — self-hosted (Docker), лицензия Apache 2.0, платить не за что
  сверх стоимости самого VPS.
- **Yandex Disk** (если используется) — обычный бесплатный тариф Яндекс.Диска
  (до 10-20 ГБ бесплатно) достаточен для .txt-файлов официальных документов;
  платный тариф не требуется при разумном объёме файлов.
- **GitHub Actions** — бесплатный тир публичных/частных репозиториев обычно
  достаточен для редких (по push) и коротких (rsync + restart) деплоев.
- **Telegram Bot API** — бесплатно.
